# Controlled fixed-pool experiment source

This is the execution-time AutoJudge source snapshot, with neutral module names
and publication labels. It is isolated from later changes to the repository's
main package. See [the experiment instructions](../README.md) for installation,
offline verification, and new-run commands.

Install `../requirements.txt` and run the scripts directly from this directory.
The CLI imports this directory's `src/autojudge` at execution time.
